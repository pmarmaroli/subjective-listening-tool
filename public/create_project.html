Container Naming Rules

A container name must be a valid DNS name, conforming to the following rules:

  • Must start or end with a letter or number; can contain only letters, numbers, and hyphens (-).
  • Every hyphen must be immediately preceded and followed by a letter or number; no consecutive hyphens.
  • All letters must be lowercase.
  • Must be 3–63 characters long.
